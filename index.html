Як увімкнути озвучування тексту

Озвучування сторінки виконує програма читання екрана, яка вже вбудована у ваш телефон або комп’ютер. Її потрібно увімкнути один раз — після цього вона читає будь-який сайт.

iPhone або iPad

  1. «Налаштування» → «Доступність» → «VoiceOver» → увімкнути перемикач.
  2. Або скажіть Siri: «Увімкни VoiceOver».
  3. Щоб озвучити лише цю сторінку: «Налаштування» → «Доступність» → «Вимовляння вголос» → «Вимовляти екран», далі проведіть двома пальцями від верхнього краю екрана вниз.

Android

  1. «Налаштування» → «Доступність» → «TalkBack» → увімкнути перемикач.
  2. Швидке ввімкнення: натисніть і утримуйте обидві клавіші гучності приблизно 3 секунди.
  3. Альтернатива — «Доступність» → «Вибір вголос»: читається лише той текст, який ви позначите.

Windows

  1. Екранний диктор: натисніть Win + Ctrl + Enter (повторне натискання вимикає).
  2. Або «Параметри» → «Спеціальні можливості» → «Екранний диктор».
  3. У браузері Microsoft Edge є окрема функція «Читати вголос»: Ctrl + Shift + U.

macOS

  1. VoiceOver: натисніть Cmd + F5 (повторне натискання вимикає).
  2. Або «Системні параметри» → «Доступність» → «VoiceOver».

Збільшити текст у браузері

  • Комп’ютер: Ctrl + + (на Mac — Cmd + +), повернути початковий розмір — Ctrl + 0.
  • Телефон: розведіть два пальці на екрані або скористайтеся кнопками «A+» у цьому вікні налаштувань.

Статут, ліцензія та рішення учасників — це відскановані документи (зображення), тому програма читання екрана не може прочитати їх текст. Ми надішлемо зміст будь-якого з цих документів у зручному форматі на запит — зверніться до нас за контактами, вказаними на сайті.
